# hellwand

Open source tools for the home lab. Self-hosted, no cloud.

## TasmoFleet

A fleet manager for [Tasmota](https://tasmota.github.io/) devices: backups and restore, a settings policy
with one-click compliance, safe bulk firmware updates, MQTT, notifications and SSO.
