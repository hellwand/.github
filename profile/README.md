# hellwand

Open source tools for the home lab. Self-hosted, no cloud.

## TasmoFleet

A fleet manager for [Tasmota](https://tasmota.github.io/) devices: backups and restore, a settings policy
with one-click compliance, safe bulk firmware updates, MQTT, notifications and SSO.

[Website](https://hellwand.github.io/tasmofleet/) · [Live demo](https://hellwand.github.io/tasmofleet/demo/) ·
[Repository](https://github.com/hellwand/tasmofleet) · [Releases](https://github.com/hellwand/tasmofleet/releases) ·
[Discussions](https://github.com/hellwand/tasmofleet/discussions)

## Nova

A native Android client for Unraid NAS servers, built with Kotlin and Jetpack Compose. Available on F-Droid and as
GitHub releases.

[Website](https://hellwand.github.io/nova/) · [Repository](https://github.com/hellwand/nova) ·
[Releases](https://github.com/hellwand/nova/releases) ·
[F-Droid](https://f-droid.org/packages/io.github.nofuturekid.nova/) · [Issues](https://github.com/hellwand/nova/issues)

## OBSBOT on Linux

A command-line tool and daemon to control OBSBOT webcams on Linux, tested with the Tiny 2 Lite, and a widget for the
Dux shell.

[Repository](https://github.com/hellwand/obsbot4linux) · [Releases](https://github.com/hellwand/obsbot4linux/releases) ·
[Dux widget](https://github.com/hellwand/obsbot4linux-dux)

Unofficial community tools, not affiliated with the camera's maker. OBSBOT is a trademark of its owner.
